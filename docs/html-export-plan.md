# План: HTML-выгрузка рейда в Discord

Обновлялка прикладывает к посту рейда автономную страницу аддона Raid Helper: один HTML без сети, в нём
wasmoon (Lua на WebAssembly), исходники аддона, данные рейда, шрифты и картинки; 3D-залов нет, реплей — на плоском
полу. Сейчас её собирает `tools/web/engine.js --standalone` на node в репозитории аддона; у игрока есть только exe
обновлялки, клиент WoW и установленный аддон.

## Из чего состоит страница (рейд 08.11, ЦЛК 25, 12 попыток)

Разбор готового `raid-2026-11-08-standalone.html`: тело — gzip, в HTML — base64 (×4/3).

| Часть | Сырьё | gzip | Откуда у игрока |
|---|---|---|---|
| Данные рейда (`data.lua`) | 10,5 МБ | 2,41 МБ | SavedVariables `ManaCode_RaidHelper.lua` |
| Значки `Interface\Icons` (459 шт., вдвое меньше) | 1,19 МБ | 1,20 МБ | MPQ клиента |
| Прочие картинки клиента (экран загрузки, ачивки, LFG, рамки, эффекты) | 1,1 МБ | 1,1 МБ | MPQ клиента |
| Картинки аддона (полы 10 залов, реплей, панель) | 1,2 МБ | 1,2 МБ | папка аддона, TGA |
| `lua.js` — исходники аддона и движка | 4,78 МБ | 1,06 МБ | папка аддона + движок |
| `glue.wasm`, `wasmoon.js`, `web.js`, `runtime.js`, `host.js` | 0,48 МБ | 0,17 МБ | только движок |
| Шрифты Friz и Arial Narrow | 0,19 МБ | 0,11 МБ | `Fonts` / MPQ клиента |
| **Итого** | 19,9 МБ | 7,34 МБ → **9,8 МБ** HTML | |

Картинки сейчас выбирает прогон Lua в node: сводки всех попыток с наведением на всё, таймлайн, реплей каждой
попытки через 15 с. У игрока node нет — набор нужно знать без прогона.

## Замеры на Go

| Что | Время | Итог |
|---|---|---|
| gzip уровня 9 тела 08.11 (19,9 МБ), `compress/gzip` | 1,2 с | 7,33 МБ (node — 7,34) |
| То же, уровень по умолчанию | 0,7 с | 7,37 МБ |
| 1559 значков «с запасом» из MPQ: чтение, BLP, уменьшение вдвое, PNG | 1,7 с | 4,1 МБ PNG, 2,6 КБ на значок |
| Движок без исходников аддона (wasmoon, js, `shim/api/boot.lua`, имена заклинаний, шаблон) | — | 0,87 МБ, gzip 0,25 МБ |

«С запасом» — значки всех заклинаний записи этого рейда (474) и всех id из `data/` аддона (1085); на 08.11 страница
с ними — ≈10,2 МБ gzip, **≈13,6 МБ HTML** при пределе 20 МБ. Сборка на Go целиком — 4–6 с.

## Варианты

| | A. Пакет движка отдельным файлом релиза | **B. Движок в архиве аддона, остальное — Go** | C. Прогон Lua в браузере игрока |
|---|---|---|---|
| Что едет готовым | `ManaCode_RaidHelper-web-v<версия>.zip`: движок, `lua.js`, картинки аддона в PNG, манифест | папка `ManaCode_RaidHelper/web/`: движок, имена заклинаний, шаблон, манифест (0,9 МБ) | как B + режим пробы в `boot.lua` |
| Что собирает Go | данные, картинки клиента, шрифты, упаковку | то же + `lua.js` из установленных файлов по `.toc` и картинки аддона из TGA | то же + локальный HTTP: страница в `msedge --headless` проходит сводки и реплеи, сервер отдаёт картинки из MPQ и записывает, что спрошено |
| Набор картинок | по манифесту и id записи, с запасом | по манифесту и id записи, с запасом | точный, как у node |
| Версия движка = версия аддона | отдельная загрузка на версию, кэш | всегда: лежит в той же папке | всегда |
| Без сети и без браузера | нужна сеть один раз на версию | да | без Edge/Chrome — откат к B |
| Чужие ассеты в релизе | нет (картинки клиента не кладём) | нет | нет |
| Риски | лишний файл релиза держать в лад с аддоном | Go повторяет выбор файлов из `.toc` | 15–35 с браузера на рейд, хрупкий проход без CDP, вдвое больше работы |

**Выбор — B.** Движок едет вместе с аддоном той же версии, который игрок и так ставит обновлялкой, — ни отдельной
загрузки, ни рассинхрона, работает без сети. Исходники аддона уже лежат у игрока без комментариев (чистовик
`release.js`), повторять их в пакете незачем. Точный набор картинок (C) не нужен: с запасом 08.11 занимает 13,6 из
20 МБ, а нехватающая картинка на странице — прозрачная, не ошибка. Нет `web/` в папке аддона (поставлен с CurseForge
или вручную) — обновлялка берёт `web/` из лёгкого архива GitHub той же версии и кэширует в
`%LOCALAPPDATA%\ManaCode\web\<версия>\`.

## Что меняется в аддоне (`tools/release.js`, только архивы GitHub)

| Что | Объём |
|---|---|
| Папка `web/` в основной папке полного и лёгкого архивов: `wasmoon.js`, `glue.wasm`, лицензия wasmoon (MIT), `host.js`, `runtime.js`, `web.js`, `shim.lua`, `api.lua`, `boot.lua`, `standalone.html`, `spells.lua` (имена из `tools/lib/spellnames.lua`) | 0,5 дня |
| `web/manifest.json`, формат `v`: общий список картинок (`assets.uiSet()`, пути из кода `literalTextures`, картинки не из `Interface\Icons`, что нарисовал прогон по тестовым записям), списки по зоне (`icc`, `uld`…: экран загрузки, полы залов), id заклинаний из `data/`, предел маленькой запасной картинки (64 КБ), какие папки уменьшать вдвое | 0,5 дня |
| `engine.js --standalone` берёт картинки по тому же манифесту — один источник правды, страница node и Go совпадают | 0,5 дня |
| Сборка CurseForge — без `web/` | в той же правке |

Формат очереди `discord` (v2) не меняется: рейд в записи Go находит по `id` (id КД) и `start`/`finish` поста.

## Что делает обновлялка

| Шаг | Как | Объём |
|---|---|---|
| Движок | `web/` установленного Raid Helper; нет или `manifest.v` незнакомый — `web/` из лёгкого архива той же версии | 0,5 дня |
| Данные рейда | тот же `ManaCode_RaidHelper.lua`, что и очередь: сегменты и верхние ключи текстом (как `db.readRecord`), рейд поста (как `pickRaid`: id КД, треш рядом ±1 ч), урезка сегмента (как `stripSeg`), имена заклинаний из словарей сегментов; тест — совпадение с node на `tools/fixtures/rec_small.lua` | 1,5 дня |
| `lua.js` | файлы `.lua` из `.toc` (без `lead/`), `shim/api/boot.lua`, имена заклинаний движка со значками | 0,5 дня |
| Справочники клиента | общий чтец DBC; Spell → SpellIcon, Item → ItemDisplayInfo + `Cache\WDB\<локаль>\itemcache.wdb`, Achievement; предметы — добыча записи и расходники, ачивки — из записи | 1 день |
| Картинки | BLP (есть `blp.go`) и TGA аддона → уменьшение вдвое для значков и полов → PNG; кэш в `%LOCALAPPDATA%\ManaCode\icons` | 0,5 дня |
| Шрифты | Friz — `webFont` (есть, `discordfont.go`), Arial Narrow — из `Fonts`/MPQ | 0,1 дня |
| Упаковка и предел | заголовок JSON + части → gzip 9 → base64 в шаблон; предел 20 МБ с запасом 2 %: не влезло — развёртка только у последнего убийства каждого босса, затем добивка значками `data/` до предела (как `standalone`) | 0,5 дня |
| Отправка | после картинок — отдельным последним сообщением (`text/html`, `raid-<день>.html`), повтор после обрыва — с него; 413 — пост без выгрузки и строка в discord.log; без вебхука — файл рядом с картинками в `Screenshots\RaidHelper`; «Отправить снова» собирает заново | 0,5 дня |
| Тесты, `docs/spec.md`, строки окна | `httptest` для вложения, golden по фикстуре | 1 день |
| **Итого** | обновлялка ≈6 дней, аддон ≈1,5 дня | |

Не влезло и урезанной (≈3× рейда 08.11 по данным) — пост уходит без выгрузки, в первом сообщении строка «выгрузка

## Решает заказчик

1. Выгрузка — всегда или галочкой «Прикладывать выгрузку» в панели Discord (по умолчанию вкл.)?
2. Текст сообщения с файлом: например, «Рейд целиком: скачать и открыть в браузере».
3. Не влезла даже урезанная — пост без выгрузки с припиской (как в плане) или не слать пост вовсе?
4. Предел — 20 МБ всегда или настройка: серверы с бустом принимают больше, но вебхук уровень сервера не сообщает.
5. Можно ли класть `web/` (0,9 МБ, wasmoon под MIT) в папку аддона в архивах GitHub?
6. Без вебхука — сохранять HTML рядом с картинками в `Screenshots\RaidHelper`?
