ManacodeUpdate устанавливает и обновляет аддоны Manacode и ваши проекты аддонов с публичными релизами GitHub.

Что нового в 1.9.0:
- Raid Helper: новая группа «Модули» — галочка «Сборщик» (Спамер, вкладка «Рейд», шаблоны рейдов) ставит его отдельной папкой рядом с аддоном. По умолчанию включена.
- «Удалить аддон…»: если кнопка недоступна, рядом написано почему — «закройте игру», «папка разработки».
- Установка аддонов надёжнее: запись в AddOns ждёт две минуты после запуска игры, архивы распаковываются на диск без памяти, проверка путей строже.

Скачайте `ManacodeUpdate.exe` и замените старую копию. Программа умеет обновлять себя кнопкой внизу окна и автоматически при включённом автообновлении. Для установки и удаления аддонов полностью закройте игру.

What's new in 1.9.0:
- Raid Helper: a new "Modules" group — the "Raid builder" checkbox (Spammer, the "Raid" tab, raid templates) installs it as a separate folder next to the addon. On by default.
- "Uninstall addon…": when the button is unavailable, the reason is shown next to it — "close the game", "development folder".
- Safer addon installs: writes to AddOns wait two minutes after the game starts, archives are unpacked to disk instead of memory, path checks are stricter.

Download `ManacodeUpdate.exe` and replace the previous copy. The app also supports self-updates. Fully close the game before installing or removing addons.
